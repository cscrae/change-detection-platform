# 参考底图、经纬网与 POI

地图新增“地图与坐标”面板，可分别开关参考底图、经纬网和 POI。现有两期影像、检测结果和选区继续叠加在同一地图上。

## 显示坐标与影像匹配

- 参考底图使用 WGS84 基准的 EPSG:3857 XYZ 网格，与 Leaflet 默认的 Web Mercator 一致；经纬度读数和 POI 使用 WGS84 `[经度, 纬度]`。[Leaflet 官方坐标系说明](https://leafletjs.com/reference.html#crs-epsg3857)
- 影像必须具有正确的源 CRS；平台已有 Rasterio 重投影流程将 EPSG:4526、EPSG:4490 等数据转换到显示网格。经纬网直接由当前视口计算，不使用屏幕像素假装地理坐标。
- 经纬网默认显示，平移、缩放和窗口尺寸变化后自适应更新，限制线数。面板常驻显示地图中心经纬度，鼠标移动到地图上时显示鼠标位置，保留六位小数。
- 不将 GCJ-02、BD-09 底图直接叠加。自定义服务必须明确声明坐标基准；填写错误声明不会自动消除数据偏移。显示重投影不等于测绘级精度验证，仍需核实原始定位及地物控制点。

## 底图配置

没有配置时使用 OpenStreetMap 标准 XYZ。只有当前可见瓦片会按 Leaflet 正常浏览方式请求，保留浏览器缓存、Referer 和可见来源署名，不提供批量下载、离线抓取或地图瓦片压测。[OSM 官方瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)

Windows 开发环境可把 `frontend/.env.example` 复制为 `frontend/.env.local` 后填写：

```dotenv
VITE_BASEMAP_URL=https://maps.example.org/tiles/{z}/{x}/{y}.png
VITE_BASEMAP_CRS=EPSG:3857
VITE_BASEMAP_DATUM=WGS84
VITE_BASEMAP_ATTRIBUTION=单位地图服务名称
VITE_BASEMAP_MAX_NATIVE_ZOOM=19
```

示例地址不是可用业务服务，需替换为授权地址。以上字段留空使用默认服务；自定义 URL 须同时提供 CRS、datum 和署名。仅支持 HTTP(S) 或同源地址，模板须包含 `{z}`、`{x}`、`{y}`。WMS、TMS 或其他 WMTS 参数不能直接填成 XYZ，应先提供兼容的瓦片入口。

修改 Vite 环境后须重启开发前端；生产环境须重新构建。服务器 Compose 已将同名变量贯通到前端构建参数，详见 [服务器部署说明](../deploy/SERVER_SCALE.md)。`VITE_*` 会进入公开前端代码，不能放置服务端私钥或共享登录密码。

网络不能访问默认服务时，面板显示参考底图不可用；原有遥感影像、经纬网和检测仍可运行。可以关闭参考底图，或换成单位内网服务。

## POI 数据

本轮实现的是可配置的数据接口和地图图层，尚未提供实际业务 POI 数据集。默认从项目 `data/poi/*.geojson` 只读加载；缺少文件会显示“尚未配置 POI 数据”，不会生成示意点冒充真实地点。

真实数据应是 WGS84 Point GeoJSON；可包含 `name`、`category`、`address`。明确声明 EPSG:3857 的数据由后端转换；GCJ-02/BD-09、未知或冲突声明会拒绝。格式、校验命令、容量限制和服务器挂载方式见 [POI 数据接入](POI_DATA.md)。

放大地图至 11 级后，前端按当前视野请求：

```text
GET /py/local/poi?bbox=西,南,东,北&limit=500
```

每次最多显示 500 个地点；超过上限时提示缩小范围。移动地图后延迟查询，旧请求会取消；切页停用、卸载时清理请求、计时器和图层。POI 可点击查看名称、分类、地址及经纬度。内容通过 DOM 文本写入，不把外部名称作为 HTML。[Leaflet 提示内容说明](https://leafletjs.com/reference.html#tooltip)

POI 用于地图参考，不改变影像时间、行政区、模型输入或检测结果。业务数据来源及许可由实际提供方确定，API 返回来源标识供核查。

## 验证范围

地图工具单测覆盖坐标格式、网格边界、底图声明及 POI 异常输入；后端测试覆盖 bbox、容量、CRS 转换、缺数据、缓存刷新和属性过滤。本地浏览器已核对控件位置、可见署名、经纬网、四页切换恢复、图层开关，以及隔离 POI 的点击弹窗和自动平移。390×844 视口下控件没有横向溢出，地图工具与坐标面板不重叠；临时夹具明确标为测试内容，未进入业务 POI 目录。

整月拼接瓦片现在按月份与版本使用短查询，服务器仍校验完整场景成员和版本，避免数百个切片 ID 造成请求地址过长。概览及邻近预览共用一个后台并发槽，当前视野的细节优先加载；共享盘冷读整市概览仍可能较慢。已有测试集是分散切片，切片外仅显示参考地图，不能据此判断遥感影像缺失。

服务器尚未确定，参考底图在目标网络的可达性、真实 POI 覆盖和大范围计算性能仍需部署后验证。
